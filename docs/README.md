# Документация AI Talks

Документы находятся внутри репозитория и доступны в отдельном клоне. Команды в технических руководствах выполнять из корня репозитория, если не указано иное. Старые записи этапов описывают состояние на дату записи; актуальные возможности сверять с [состоянием реализации](IMPLEMENTATION_STATUS.md).

## Пользователям

| Материал | Назначение |
| --- | --- |
| [Руководство пользователя](guides/2026-11-15-ai-talks-user-manual-ru.html) | Канонический HTML-источник справки по входу и выбору пространства, чату, архивной истории, трём режимам общения и управлению. Перебивание голосом явно отмечено как следующий, ещё не реализованный этап. |
| [Режимы общения](guides/2026-11-15-ai-talks-communication-modes-ru.md) | Кнопочный голосовой режим и его отличие от живого диалога. |
| [Потоковый ответ](guides/2026-11-15-ai-talks-streaming-ru.md) | Поведение выдачи и озвучивания; описание старого интерфейса с двумя переключателями помечено как историческое. |

После изменения руководства выполнить из корня репозитория:

```bash
python3 docs/sync_user_manual.py
python3 docs/sync_user_manual.py --check
npm --prefix frontend run build
```

Скрипт обновляет включаемую в сборку копию `frontend/src/user-manual-ru.html`. Обе версии входят в Git. В руководстве используется только доверенный HTML из репозитория, без текста ответов модели и пользовательских документов.
