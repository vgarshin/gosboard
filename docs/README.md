# Документация AI Talks

Документы находятся внутри репозитория и доступны в отдельном клоне. Команды в технических руководствах выполнять из корня репозитория, если не указано иное. Старые записи этапов описывают состояние на дату записи; актуальные возможности сверять с [состоянием реализации](IMPLEMENTATION_STATUS.md).

## Пользователям

| Материал | Назначение |
| --- | --- |
| [Руководство пользователя](guides/2026-11-15-ai-talks-user-manual-ru.html) | Общие разделы справки в приложении. Вход, чат, источники, архив и три режима общения. |
| [Руководство редактора](guides/2026-11-15-ai-talks-user-manual-ru.html#manual-editor) | Общие разделы, управление своими и назначенными пространствами и базами знаний, пределы доступа редактора. |
| [Руководство администратора](guides/2026-11-15-ai-talks-user-manual-ru.html#manual-admin) | Общие разделы, управление всеми пространствами и базами знаний, назначения, аккаунты и просмотр переписки с аудитом. |
| [Матрица доступа AI Talks](guides/2026-11-25-ai-talks-rbac-ru.md) | Права пользователя, редактора и администратора в чатах, пространствах, базах знаний и настройках. |
| [Режимы общения](guides/2026-11-15-ai-talks-communication-modes-ru.md) | Кнопочный голосовой режим и его отличие от живого диалога. |
| [Потоковый ответ](guides/2026-11-15-ai-talks-streaming-ru.md) | Поведение выдачи и озвучивания; описание старого интерфейса с двумя переключателями помечено как историческое. |

После изменения руководства выполнить из корня репозитория:

```bash
python3 docs/sync_user_manual.py
python3 docs/sync_user_manual.py --check
npm --prefix frontend run build
```

Скрипт обновляет включаемую в сборку копию `frontend/src/user-manual-ru.html`. Источник и копия входят в Git. Приложение показывает общие разделы и разделы для роли действующей сессии. Атрибут `data-roles` в оглавлении задаёт роли для раздела. В руководстве используется только доверенный HTML из репозитория, без текста ответов модели и пользовательских документов.
